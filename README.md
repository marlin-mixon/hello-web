# Hello Web Template

A clean, framework-agnostic starting template for web applications built with modern tools and containerized with Docker.

---

## Tech Stack

* **Frontend:** TypeScript, Tailwind CSS, Nginx
* **Backend:** Python, FastAPI
* **Orchestration:** Docker Compose

---

## Project Structure

```text
hello-web/
├── backend/          # Python components (Endpoints configured under /app)
├── frontend/         # HTML, TypeScript, and Nginx configurations
└── docker-compose.yml # Docker multi-container setup
